# VDSina — кастомная интеграция Home Assistant

Настройка через интерфейс, координатор данных, сенсоры серверов с атрибутами и кнопка обновления. Интервал по умолчанию **60 минут**.

## Установка

1. Из архива скопируйте папку `custom_components/vdsina` в `/config/custom_components/vdsina` на вашей HA.
2. Перезапустите Home Assistant.
3. Откройте **Настройки → Устройства и службы → Добавить интеграцию → VDSina**.
4. Выберите **userapi.vdsina.com** для вашей панели **cp.vdsina.com**. Другой доступный вариант, userapi.vdsina.ru, предназначен для аккаунта панели .ru.
5. Введите постоянный API-токен из сведений пользователя панели VDSina и оставьте интервал **60 минут**.

Для каждого VPS есть общий расход, лимит, процент использования, входящий и исходящий трафик за текущий календарный месяц. Расходы показаны в GiB (1 GiB = 1024³ байт), лимит в TiB (1 TiB = 1024⁴ байт). Такой пересчёт соответствует соотношению чисел на присланном скриншоте: 130,7 / 1024 × 100 ≈ 12,76%. Панель подписывает эти величины как GB/TB; в HA используются точные обозначения двоичных единиц GiB/TiB.

Общий расход берётся из bandwidth.current_month, лимит — строго из data.traff.bytes ответа server/ID. Процент рассчитывается по этим двум значениям. Неизвестный или нулевой лимит не подменяется предположением: процент будет unknown.

Входящий и исходящий интернет-трафик суммируются по vnet_rx / vnet_tx почасовых блоков server.stat/ID. Запрос задаёт период с первого числа месяца 00:00:00 до момента опроса в Europe/Moscow. Локальный сетевой трафик не учитывается. Общий расход и сумма направлений могут расходиться из-за задержки почасовой статистики и округления.

## Настройки

В меню интеграции **Настроить** доступны интервал 5–1440 минут и необязательное поле нового API-токена. Пустое поле оставляет текущий токен. При изменении параметров интеграция перезагружается.

Кнопка **Обновить данные** выполняет внеочередной опрос. Первый опрос выполняется при добавлении/запуске HA; при сетевых сбоях HA может повторить попытку раньше обычного интервала. 60 минут — интервал штатного опроса, не запрет на первоначальный опрос, восстановление и ручное обновление.

Если токен станет недействительным, HA запросит повторную авторизацию. Токен другого аккаунта не заменит данные существующих серверов: добавьте другой аккаунт отдельно.

## Сущности

Устройство аккаунта VDSina содержит:

- Баланс, бонусный и партнёрский балансы.
- Прогноз отключения аккаунта, оставшиеся календарные дни, количество серверов.
- Время последнего успешного обновления.
- Кнопку обновления.

Для каждого VPS автоматически создаются девять сенсоров:

| Сенсор | Состояние |
|---|---|
| `<имя VPS> баланс` | Общий основной баланс аккаунта, как в Webhost1 |
| `<имя VPS> статус` | active / new / block / notpaid / неизвестный статус API |
| `<имя VPS> IP` | Основной адрес; полный список находится в атрибуте ips |
| `<имя VPS> тариф` | Название тарифного плана |
| `<имя VPS> использование трафика` | Расход за текущий месяц в GiB |
| `<имя VPS> лимит трафика` | Месячный лимит в TiB |
| `<имя VPS> использовано трафика в процентах` | Общий расход / лимит × 100 |
| `<имя VPS> входящий трафик` | Получено из интернета за текущий месяц в GiB |
| `<имя VPS> исходящий трафик` | Отправлено в интернет за текущий месяц в GiB |

Сенсор сервера содержит атрибуты:

| Атрибут | Значение |
|---|---|
| provider | VDSina |
| IP, ips | Основной и все возвращённые IP |
| Order, server_id | Стабильный ID сервера VDSina |
| due_date, forecast | Прогноз отключения аккаунта в отображаемом и ISO-формате |
| days_left, message | Дни до прогноза и текст для ваших уведомлений |
| status, status_text | Статус услуги и выполняемая операция |
| balance, currency | Основной баланс и валюта |
| tariff, datacenter, country | Тариф и размещение |
| hostname, os | Имя хоста и ОС |
| cpu, ram, disk, traffic_limit | Выделенные ресурсы из API; RAM и диск в GB, лимит трафика в TB |
| bandwidth | Трафик за текущий/предыдущий месяц в байтах, если API возвращает |
| service_end | Срок услуги из API |
| autopay, autoprolong, autorun | Автопродление и автоматический запуск |
| last_update, execution_seconds | Время и длительность последнего успешного опроса |
